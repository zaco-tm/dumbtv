# The ports: what the prototype has, and what the app has

The prototype is the design and this app is the product, so a component is ported when its
behaviour is matched, not when its code looks similar. The table that says what each one has to
match is [docs/superpowers/averagetv-parity.md](../../../docs/superpowers/averagetv-parity.md); this
file is the app's side of it: what exists, and what is still to come.

## The components

| In the prototype | In the app | State |
|---|---|---|
| `@charcoal/line-sidebar` (`src/components/ui/line-sidebar.tsx`) | `src/ui/charcoal/Rail.tsx` | Not ported yet (task 7). |
| `@charcoal/rating` (`src/components/ui/rating.tsx`) | `src/ui/charcoal/Rating.tsx` | Not ported yet (task 7). |
| `@charcoal/carousel` (`src/components/ui/carousel.tsx`) | — | **Not ported, and it will not be.** The sketch has no carousel: the Favorites row and the ranked list are driven by the focus, not by dragging. It stays in the prototype because it is free there. |

## The native modules

The JavaScript's way into Android. The shape is already the final one; what each stub does and what
is still missing is written down in the module's own source file.

| Module | What it answers | Now |
|---|---|---|
| `parent_pin` | `check(pin)`, `set(pin)` | **Real.** The salted SHA-256 hash in the `parent_pin` file, in the format the Java app uses. |
| `home_mode` | `isHome()`, `setHome(on)`, `refresh()` | A stub. `isHome()` asks the system who holds the HOME role; `setHome()` only records the request, because the real switch needs the television's own ADB (task 8). |
| `inputs` | `list()` | A stub. It reads the displays Android reports, which on a television are the HDMI inputs. The input screen itself is task 8's work. |
| `sleep` | `start(minutes)`, `cancel()` | A stub. It writes the end of the timer into the settings file, in the Java app's keys. The blanking is task 8's work. |
| `prefs` | `get(file, key)`, `set(file, key, value)` | **Real**, for the `settings` and `home-ui` files. The PIN's file is not reachable from here. |
| `night` | `isNight()` | A stub with the Java app's rule: the theme has the last word, and without sun times it is night from 18:00 to 06:00. |
